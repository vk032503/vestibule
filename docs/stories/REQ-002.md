# REQ-002 — Identity & Idempotency

**Phase:** 1 · **Pipeline:** full · **GitHub issue:** #2

## Goal
Define and enforce the identity contract for documents and chunks across the framework.
Every document has a deterministic `doc_id`; every chunk has a deterministic `chunk_id`
derived from it. All writes downstream use these IDs so retries overwrite instead of duplicating.
This is Contract #2 — the foundation for exactly-once semantics under at-least-once delivery.

## In scope
- `derive_doc_id(source: str, blob_path: str) -> str` — sha256 hex digest
- `derive_chunk_id(doc_id: str, chunk_index: int) -> str` — sha256 hex digest
- Validation of ID format (hex, correct length) with `IdentityInvalid` error class (PERMANENT)
- Helper to iterate a batch of chunk indices → chunk_ids for a given doc_id
- Unit tests: determinism, uniqueness across inputs, invalid inputs, batch generation
- Property-based tests (hypothesis) proving determinism over random inputs

## Out of scope
- Upsert / write logic (belongs to individual store adapters)
- Delete-before-reingest orchestration (belongs to the metadata handler, later phase)
- Any I/O — this module is pure functions only

## Acceptance criteria
1. Same `(source, blob_path)` inputs always produce the same `doc_id` — verified by property test.
2. Different inputs produce different `doc_ids` — verified over 1,000 random pairs.
3. Same `(doc_id, chunk_index)` inputs always produce the same `chunk_id`.
4. IDs are lowercase hex strings of length 64 (sha256).
5. Invalid inputs (empty strings, None, non-string) raise `IdentityInvalid` classified PERMANENT.
6. Batch generation for N chunks matches individually-generated IDs one-for-one.

## Contract touchpoints
- Arrival Envelope: consumes `source` and `blob_path` from an envelope to derive `doc_id`
- Idempotency: this IS the identity half of Contract #2
- Ledger: `doc_id` becomes the primary key of the ledger (defined here, used in REQ-003)
- Failure taxonomy: `IdentityInvalid` = PERMANENT

## Budget
- p95 latency: < 1ms per ID derivation (pure hash)
- Cost per document: zero (no external calls)
